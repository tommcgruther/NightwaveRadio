# NIGHTWAVE Radio

Native Android internet radio app for Pixel. Supports Radio Browser live stations, Internet Archive DJ sets, favourites, custom stream URLs, MP3 capture for compatible streams and Android Auto media browsing.

Source is packaged in `nightwave-src.tar.xz.b64` for the GitHub Actions APK build. The original full source ZIP remains available in ChatGPT. This is a development build and has not been tested on a Pixel.
